KMP Device Hub puts every Android emulator, connected Android phone and iOS simulator in one panel, and adds a Network Inspector for your Kotlin Multiplatform app.

1. Install

  1. Use Android Studio or IntelliJ IDEA, version 2025.1 or newer.
  2. Open Settings (Android Studio → Settings on macOS), then Plugins → Marketplace.
  3. Search for KMP Device Hub, click Install, and restart the IDE.

2. Make sure the device tools are available

  • Android: the Android SDK with Platform-Tools (adb) and the Emulator. The plugin finds them through your project's local.properties (sdk.dir), ANDROID_HOME, or the default Android Studio location.
  • iOS: macOS with Xcode and at least one iOS simulator runtime installed.
  • Physical Android phones need USB debugging turned on. To connect over Wi-Fi, use Wi-Fi Debugging in the plugin's toolbar.

If something is missing, the panel tells you what and how to fix it. There's nothing else to configure.

3. Use the KMP Devices panel

  1. Open the KMP Devices tool window on the right side of the IDE.
  2. Select a device. Double-click a stopped emulator or simulator, or click Start, to boot it.
  3. On the App tab, your Android applicationId and iOS bundle id are filled in from your project. Launch, Stop, Clear data or Uninstall your app.
  4. Use the other tabs to switch dark mode, text size and app language (including right-to-left), manage permissions, open deep links, simulate location and network conditions, send push notifications, and apply test presets.
  5. Turn on All running devices to apply an action to every running device at once.
  6. Drop an .apk or simulator .app on a device to install it.

Logs

Open KMP Logs (at the bottom), pick a running device and your app, and press Start. On iOS, tick Include println to see Kotlin/Native println output (this relaunches the app).

4. Optional: the Network Inspector

To see your app's HTTP calls in the KMP Network tool window (at the bottom), add the small debug library and install it in your HTTP client:

// build.gradle.kts (commonMain, or debugImplementation in an Android-only app)
implementation("io.github.khubaibkhan4:devicehub-network:0.1.0")

// Ktor (Android, iOS, JVM)
HttpClient { install(DeviceHubNetwork) { enabled = isDebugBuild } }

// OkHttp / Retrofit (Android)
OkHttpClient.Builder().addInterceptor(DeviceHubInterceptor { enabled = BuildConfig.DEBUG })

Run your app on an emulator or simulator and its calls appear in KMP Network. Android devices connect through adb reverse, which the plugin sets up for you. Enable the library only in debug builds.

Complementary and conflicting plugins

  • Complementary: the Kotlin Multiplatform plugin by JetBrains (project wizard and run configurations), and KMP Dependency Hub (adds KMP libraries to the right source sets).
  • It works alongside Android Studio's built-in Device Manager and Running Devices, using the same adb and emulators.
  • No known conflicts. The Network Inspector uses port 38383 on your machine. If another tool uses that port, the KMP Network window says so.
